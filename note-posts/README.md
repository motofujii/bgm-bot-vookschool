## 導線設計の考え方

### 4フェーズ構成
1. **共感・集客（第3〜4回）**：売り込みゼロ。検索・SNSから新規読者を集め、フォローしてもらう。CTAは「フォロー＋スキ」のみ。有料noteはプロフィールと記事末尾に1行触れる程度。
2. **価値提供（第5〜7回）**：有料noteの3本柱（お金・家族・仕事）から1テーマずつ無料で切り出す。「無料でここまで出すなら有料は…」という期待を作る。CTAは記事末の有料note案内（控えめ〜中）。
3. **オファー提示（第8〜9回）**：商品そのものを主役に。付録スプシのスクショ・目次・FAQで購入判断材料を全部渡す。CTAは強め。
4. **クロージング（第10〜12回）**：ストーリーで感情を動かし、値上げ締切で背中を押す。第11回で締切告知→第12回当日23:59値上げ。

### 値上げ（締切）の設計 ※要事前決定
- 例：現行価格 → 9/17(木) 23:59 に +500〜1,000円 値上げ
- 「期間限定割引」より「値上げ予告」の方がnoteでは信頼を損ねにくい（元に戻さないこと）
- 値上げ幅と日付は第11回公開前までに確定し、第8回以降の記事末に「9月に値上げ予定」と予告を入れておく

### 毎回共通のフォーマット
- 記事末に固定CTAブロック（有料noteリンク＋一言）※フェーズにより強弱
- 過去記事への内部リンクを1〜2本入れて回遊させる
- ハッシュタグ：#ワーママ #退職 #仕事辞めたい #ワーキングマザー #子育てと仕事（毎回3〜5個）
- 公開直後にX（旧Twitter）で告知（各記事ファイルに告知文を用意）

### KPIの目安
- フェーズ①：フォロワー増・スキ数
- フェーズ②：記事→有料noteページへのクリック
- フェーズ③④：販売数（第11・12回の週が山になる想定）

- 既存2回分の内容と重複しそうなら、第3回・第4回を後ろのネタと差し替えて調整する
