## コンセプト（2026/07 全面改訂）
**「売る投稿」ではなく「信頼されるエッセイ」を通常発信にする。**

- 想定読者：**フリーランスという働き方に、うっすら憧れているワーママ**。まだ「退職する」とは決めていない。検索するとしたら「フリーランス ワーママ 現実」「会社員 向いてない」のような温度感。
- 読者がほしいのは売り文句ではなく、**一歩先を歩いている人の正直な日常**。エッセイで「この人の書くものは信用できる」を積み上げ、有料noteは"この人がまとめた実用版"として自然に選ばれる状態を作る。
- 各記事は単体で読み物として成立させる。**セールス回・値上げカウントダウン回は作らない。**

## 売れる仕組み（エッセイなのにどこで売るか）

1. **毎回同じ「静かなフッター」**：全記事の末尾に固定2〜3行（下記）。毎週同じだから景色になり、押し売り感が出ない。買う気になった読者がいつでも入口を見つけられる。
2. **エッセイの中に道具が"登場"する**：第6回でスプレッドシートが、第7回で夫との話し合いが、物語の小道具として自然に出てくる。「紹介」ではなく「登場」。
3. **固定記事（プロフィール直下）が販売ページを担う**：毎週の記事は売らない代わりに、プロフィールと固定記事に導線を常設。エッセイで信頼→プロフィールへ→固定記事→購入、の順路。
4. **正直さそのものを営業にする**：第8回「会社員のほうが向いてる人もいる」のような"売れなくなる話"をあえて書く。これがいちばん信頼を作る。

### 固定フッター（全記事共通・コピペ用）
```
最後まで読んでくださって、ありがとうございます。
毎週木曜21時に、会社を辞めてフリーランスになったワーママの日々を書いています。
「辞めたいけど、こわい」の"こわい"を実務でほどくためのnoteはこちら → （有料noteリンク）
```

## 見えない設計（読者には見せない構造）

- **前半（3〜5回）**：フリーランス生活の質感を見せて「憧れ」の解像度を上げる。売り気配ゼロ。
- **中盤（6〜8回）**：お金・家族・（仕事）という有料noteの3本柱を、ノウハウではなく**体験談として**通過する。道具は物語の中に登場させるだけ。
- **終盤（9〜12回）**：「いつか」と言っている読者自身に焦点を移し、1年の節目で感情を動かし、最終回だけ有料noteの成り立ちを正面から（ただしエッセイとして）語る。
- 第12回のあと、次シリーズへ続く。有料noteは固定記事＋フッターで恒常的に売れ続ける設計なので、シリーズ終了＝販売終了にならない。

## 実際の時系列(記事全体で統一すること)
- 「退職する」と伝えた：約1年前(2025年夏〜秋頃)
- 最終出社：2026年3月 / 正式な退職：2026年5月
- 2026年9月時点で言えるのは「**退職すると言ってから1年**」(「退職して1年」ではない)
- フリーランスとしての稼働月数・収入などの数字はすべてダミー。公開前に実際の値に置き換える

## 運用メモ
- 各記事800〜1,600字。木曜夜（寝かしつけ後）にスマホで読み切れる長さ
- ハッシュタグは毎回3〜5個：#ワーママ #フリーランス #エッセイ #働き方 #子育てと仕事 あたりから
- 公開直後にXで告知（各ファイルに告知文あり）。エッセイの一文をそのまま引用する形が刺さりやすい
- KPI：フォロワー増・スキ率・プロフィール→固定記事へのクリック。販売数は固定記事経由で計測
- 有料noteの値上げをする場合も、通常記事では告げず固定記事とXのみで告知（エッセイの信頼を守る）
